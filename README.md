Wolfenstein 2009 Mod Source

This repository contains source code and modifications from my Wolfenstein (2009) modding project.

Project Goals

The project focuses on improving and modifying different parts of Wolfenstein (2009), including:

Performance and CPU-related improvements
AI and enemy behavior
Memory management and stability
Effects and rendering
Audio and voice behavior
Engine and gameplay modifications
